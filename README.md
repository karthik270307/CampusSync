# CampusSync

CampusSync is a centralized university student club event and resource management platform.

## Technology Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Framer Motion
- Lucide React
- Recharts
- React Hot Toast

### Backend
- Node.js
- Express
- TypeScript
- Zod
- JWT
- Mongoose

### Database
- MongoDB

## Project Structure

- `client` - React frontend
- `server` - Express backend
- `database` - database-related resources
- `docs` - project documentation
